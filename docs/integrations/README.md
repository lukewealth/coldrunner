## Quick Reference

### Currently Used (Phase 1)

- **Backend:** Express, TypeScript
- **Frontend:** React, Vite, Tailwind CSS
- **AI:** Google Gemini API
- **APIs:** Google Places, Firecrawl, Hunter.io, Apollo.io, PageSpeed Insights
- **Protocol:** MCP (Model Context Protocol)
- **Database:** In-memory (SQLite-ready)

### Planned (Phase 2-4)

- **Local AI:** Ollama, Qwen, DeepSeek, BGE-M3
- **Crawling:** Crawl4AI, Playwright
- **Vector DB:** Qdrant
- **Database:** PostgreSQL, Redis
- **Queues:** BullMQ
- **Backend:** NestJS (migration from Express)
- **Frontend:** Next.js (migration from React SPA)
- **Monitoring:** OpenTelemetry, Prometheus, Grafana, Loki, Sentry
- **Containers:** Docker, Kubernetes
- **Auth:** JWT, OAuth2

## Notes

> **Version numbers and documentation URLs may change over time. Always verify the latest release before upgrading dependencies.**
